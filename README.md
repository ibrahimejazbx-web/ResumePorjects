Password Strength Checker (Python)
  A simple Python command-line tool that evaluates the strength of a password based on common security rules.
  The program provides feedback on how to improve weak passwords and assigns a strength rating.

Features:
 - Checks password length (8+ characters)
 - Detects uppercase letters
 - Detects lowercase letters
 - Detects numeric digits
 - Detects special characters
 - Checks for spaces (not allowed)
 - Provides a strength rating:
    Weak
    Moderate
    Strong
 - Lists issues to improve password security

How It Works
The program evaluates a password using multiple security rules. 
Each passed rule increases the score by 1. Based on the final score, the password is classified into a strength category.
